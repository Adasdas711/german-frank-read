# Формат `.fbook`

`.fbook` — файл книги для читалки «Немецкий по Франку». В нём хранятся немецкий текст, русские подсказки по методу Ильи Франка, транскрипция IPA для каждого слова, словарь лемм и, если есть, русский перевод по предложениям.

Текущая версия формата — **2**. Код формата: `src/core.ts` (чтение, проверка, упаковка) и `src/builder-core.ts` (сборка из исходника).

## 1. Контейнер

`.fbook` — это обычный ZIP-архив (MIME `application/vnd.fbook+zip`). В нём **ровно три записи**, без подкаталогов:

| Запись          | Сжатие            | Содержимое                              |
|-----------------|-------------------|-----------------------------------------|
| `mimetype`      | нет (stored), первая в архиве | строка `application/vnd.fbook+zip` |
| `manifest.json` | deflate           | метаданные книги (раздел 2)             |
| `book.json`     | deflate           | текст, подсказки, IPA (раздел 3)        |

Схема та же, что у EPUB: несжатый `mimetype` в начале позволяет определить тип файла по первым байтам.

```
$ unzip -lv books/rotkappchen-demo.fbook
 Length   Method    Size  Name
      25  Stored      25  mimetype
    1219  Defl:N     737  manifest.json
   71389  Defl:N   22292  book.json
```

### Ограничения безопасности при чтении

Функции `inspectZip` и `safeUnzip` (`src/core.ts`) сначала разбирают центральный каталог ZIP и только потом распаковывают. Файл отклоняется, если:

- архив или его распакованное содержимое больше **32 МБ**;
- архив многотомный, зашифрован, в нём больше 250 записей или есть метод сжатия кроме stored/deflate;
- имя записи содержит `/`, `\` или `..` либо повторяется;
- локальный заголовок записи не совпадает с центральным каталогом;
- фактический размер или CRC-32 после распаковки не совпадает с заявленным (распаковка идёт потоком и обрывается, как только размер превышен);
- в архиве есть что-то кроме трёх записей выше, либо `mimetype` стоит не первым или сжат.

## 2. `manifest.json`

```json
{
  "format": "fbook",
  "formatVersion": 2,
  "id": "a2d660a2-2354-4f3a-b302-2937bd6e31bf",
  "revision": 3,
  "title": "Rotkäppchen",
  "titleRu": "Красная Шапочка",
  "author": "Brüder Grimm",
  "lang": "de",
  "hintLang": "ru",
  "level": "A2",
  "annotation": "auto",
  "has": ["ipa", "translation"],
  "chapters": [["Rotkäppchen (Красная Шапочка)", 14]],
  "stats": { "fragments": 14, "words": 1258 },
  "source": "Brüder Grimm, Kinder- und Hausmärchen, KHM 26 …",
  "license": "Сказка братьев Гримм — общественное достояние …"
}
```

| Поле            | Обяз. | Описание |
|-----------------|:-----:|----------|
| `format`        | да | всегда `"fbook"` |
| `formatVersion` | да | всегда `2` |
| `id`            | да | UUID книги. Это постоянный ключ: по нему в библиотеке хранятся прогресс, закладки, словарь и коллекции |
| `revision`      | да | целое число ≥ 1, номер редакции. Растёт при каждом изменении книги, например при переименовании в читалке |
| `title`         | да | название на немецком |
| `titleRu`       | нет | название на русском |
| `author`        | да | автор |
| `lang`          | да | язык текста, сейчас только `"de"` |
| `hintLang`      | да | язык подсказок, сейчас только `"ru"` |
| `level`         | да | `A1`–`C2` |
| `annotation`    | да | `"auto"` — подсказки сгенерированы автоматически; `"verified"` — каждый отрывок вычитан в сборщике |
| `has`           | да | возможности книги: обязательно `"ipa"`, плюс `"translation"`, если есть перевод |
| `chapters`      | да | непустой список пар `[название главы, число отрывков]` |
| `stats`         | да | `fragments` — всего отрывков, `words` — всего немецких слов. При проверке пересчитывается и должно совпасть |
| `source`        | нет | откуда взят текст, какие правки внесены |
| `license`       | нет | права на текст и подсказки |

## 3. `book.json`

Чтобы файл был компактным, ключи однобуквенные, а повторяющиеся строки вынесены в таблицы и заданы индексами.

```ts
type Chunk = string | [text: string, hint: number, hint2?: number | null, uncertain?: 1];

type Content = {
  v: 2;
  l: string[][];                                  // леммы (словарь)
  f: Record<string, [ipa: string, lemma?: number]>; // словоформы
  g: string[];                                    // тексты подсказок (глоссы)
  c: Chunk[][][];                                 // главы → отрывки → куски
  t?: string[][][];                               // перевод: главы → отрывки → предложения
  x?: Record<string, Record<string, string>>;     // IPA по месту (омографы)
};
```

### `c` — текст

Три уровня вложенности: **глава → отрывок → куски**. Отрывок (fragment) — это абзац или блок текста, единица навигации. Его адрес записывается как `"глава.отрывок"`, нумерация с 1 (например, `"1.3"`). Такие адреса хранятся в прогрессе и закладках.

Отрывок — массив кусков (`Chunk`). Склеив все куски, получаем немецкий текст отрывка:

- **строка** — текст без подсказки (пробелы, знаки препинания, простые слова);
- **массив** `[текст, g1, g2?, 1?]` — фраза с подсказкой:
  - `текст` — немецкий фрагмент;
  - `g1` — индекс подсказки в `g`;
  - `g2` — индекс второй подсказки, `null` или нет. Если есть, она показывается после первой через ` = `;
  - `1` в четвёртой позиции — пометка «подсказка под вопросом». Сборщик выделяет такие куски, чтобы их проверили.

Пример (начало «Красной Шапочки»):

```json
[
  ["Es war einmal eine kleine süsse Dirne", 0],
  ", ",
  ["die hatte jedermann lieb", 1],
  ", ",
  ["der sie nur ansah", 2],
  ", "
]
```

где `g[0]` = `"жила-была маленькая милая девочка; süss (süß) – сладкий, милый; die Dirne – (устар.) девушка, девочка"`. Читалка выводит это так: *Es war einmal eine kleine süsse Dirne (жила-была маленькая милая девочка; …), die hatte jedermann lieb (её любил всякий …), …*

### `g` — подсказки

Плоский список русских подсказок. Одинаковые тексты хранятся один раз, сборщик убирает дубли.

### `f` — словоформы и IPA

Ключ — словоформа в том виде, в каком она встречается в тексте (с учётом регистра). Значение — `[IPA, индекс леммы?]`:

```json
"war":    ["vˈɑːɾ", 1],
"einmal": ["ˈaɪnmˌɑːl", 2]
```

Слово — это последовательность букв, в которой могут быть апостроф или дефис (регулярка `WORD` в `src/core.ts`). **Каждое слово текста должно быть в `f`**, иначе книга не пройдёт проверку. IPA может содержать только буквы, пробелы и символы `ˈ ˌ ː ˑ . ͜ ͡ ‿ | ( ) -`.

### `l` — леммы

Словарные статьи, минимум три строки на каждую: `[лемма, перевод, часть речи]`:

```json
["einmal", "однажды; один раз; -ка (sieh einmal – посмотри-ка)", "adv"]
```

Когда читатель нажимает на слово, всплывающее окно показывает IPA из `f`, а лемму, перевод и часть речи берёт из `l` по ссылке из `f`.

### `t` — перевод (необязательно)

Есть только при `"translation"` в `manifest.has`. Структура повторяет `c`: главы → отрывки → **список предложений**. Число переведённых предложений должно совпадать с числом немецких предложений в отрывке. Немецкий текст режется по `.`, `!`, `?` и закрывающим кавычкам после них (функция `sentences`). Перевод используется в режиме «Параллельно», где каждой строке оригинала соответствует строка перевода.

### `x` — IPA по месту (необязательно)

Для омографов, когда одно и то же написание в разных местах читается по-разному:

```json
"x": { "3.12": { "modern": "mɔˈdɛʁn" } }
```

Ключ — адрес отрывка, внутри — словоформа и её IPA именно в этом отрывке. Значение из `x` важнее общего значения из `f`. Словоформа должна действительно встречаться в указанном отрывке.

## 4. Проверка (`validate`)

Книгу проверяют при каждом открытии, импорте и упаковке. Помимо структуры полей проверяется согласованность данных:

1. Число глав в `c` (и в `t`) равно `manifest.chapters.length`.
2. Число отрывков в каждой главе равно числу, указанному в `manifest.chapters`.
3. Ни один отрывок не пустой, ни один его текст не пустой.
4. Все индексы подсказок указывают на существующие элементы `g`, ссылки на леммы — на элементы `l`.
5. Каждое слово текста есть в `f`, IPA корректна.
6. В переводе столько же предложений, сколько в оригинале (по каждому отрывку).
7. `stats.fragments` и `stats.words` совпадают с пересчитанными значениями.
8. Адреса и формы в `x` существуют.

Если проверка не прошла, книга не открывается, а пользователь видит сообщение об ошибке на русском (например, «Нет IPA для «Wolf» в 1.4»).

## 5. Жизненный цикл файла

### Создание: сборщик (`fbook-builder.html`)

Книгу собирают из **исходника** `book.source.json` (тип `Source` в `src/builder-core.ts`). Его формат удобнее писать вручную:

- подсказки записаны прямо текстом: `["Es war einmal", "жила-была", "вторая подсказка?", 1]`;
- перевод хранится внутри каждого отрывка;
- большую книгу можно разбить на части (`meta.part`), которые склеивает `mergeSources`.

`compileSource` превращает исходник в `.fbook`. Она собирает таблицу `g` без повторов, заполняет `f` (IPA для всех слов должна быть готова заранее), формирует манифест со статистикой и упаковывает архив (`packBook`). Пометку `annotation: "verified"` можно поставить, только если все отрывки вычитаны и ни одна подсказка не помечена как сомнительная.

### Упаковка (`packBook`)

1. `validate(manifest, content)`.
2. ZIP: `mimetype` без сжатия, JSON-файлы с deflate уровня 9.
3. Контрольное чтение готового архива через `readBook`.

### Чтение (`readBook`)

`safeUnzip` → проверка `mimetype` → `JSON.parse` обоих файлов → `validate`. На выходе получается `{ manifest, content, bytes }`.

### Хранение в читалке

Книга хранится в IndexedDB (хранилище `books`, ключ — `manifest.id`) **в виде исходных байтов `.fbook`** вместе с копией манифеста. При открытии байты заново проходят `readBook`. Прогресс и закладки хранятся отдельно и ссылаются на адреса отрывков `"глава.отрывок"`.

- **Импорт.** Книга, `id` которой уже есть в библиотеке, повторно не добавляется.
- **Переименование** в читалке переупаковывает книгу с новым `title` и `revision + 1`, `id` не меняется.
- **Экспорт** выгружает сохранённые байты как `<slug(title)>.fbook`.
- **Резервная копия** — ZIP с `backup.json` и всеми книгами в виде `<id>.fbook`. При восстановлении книга заменяется, только если её `revision` в копии больше, чем в библиотеке.

### Обновление встроенных книг

Если вышла новая редакция встроенной книги с тем же `id`, `src/book-upgrade.ts` переносит место чтения и закладки по совпадающим немецким словам (без учёта регистра, ß = ss), потому что номера отрывков у разных редакций могут не совпадать. В `books/catalog.json` для каждой встроенной книги записаны её `id`, `revision`, SHA-256 исходного файла и исходный UUID.

## 6. Минимальный пример `book.json`

```json
{
  "v": 2,
  "l": [["Hund", "собака", "noun"], ["bellen", "лаять", "verb"]],
  "f": {
    "Der":   ["deːɐ̯"],
    "Hund":  ["hʊnt", 0],
    "bellt": ["bɛlt", 1]
  },
  "g": ["собака лает"],
  "c": [[[["Der Hund bellt", 0], "."]]],
  "t": [[["Собака лает."]]]
}
```

Подходящий к нему манифест: `"has": ["ipa", "translation"]`, `"chapters": [["Глава 1", 1]]`, `"stats": {"fragments": 1, "words": 3}`.
