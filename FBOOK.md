# Формат `.fbook`, версия 2

`.fbook` — ZIP-архив ровно из трёх записей: `mimetype` (первая, без сжатия, `application/vnd.fbook+zip`), `manifest.json` и `book.json`. Полная проверка — `validate()` и `inspectZip()` в `src/core.ts`; типы — `Manifest` и `Content` там же.

## `book.json`

- `v` — всегда `2`.
- `l` — леммы, `g` — русские подсказки, `f` — словоформы → `[IPA, индекс леммы?]`.
- `c[глава][отрывок]` — куски текста: строка или `[текст, подсказка, вторая подсказка?, 1?]`. Адрес отрывка в сообщениях — `глава.отрывок`, с единицы (например `2.16`).
- `x` — IPA по месту для омографов: `{"глава.отрывок": {форма: IPA}}`.
- `t` — перевод, если в `manifest.has` есть `"translation"`. Описан ниже.

## `t`: перевод по предложениям

`t[глава][отрывок]` — массив непустых строк, по одной на каждое предложение немецкого текста отрывка. Текст отрывка — склейка всех кусков (`plain()`), а число строк перевода должно быть равно `sentences(текст).length`.

Деление на предложения задаётся ровно этой регуляркой из `src/core.ts`:

```ts
export const sentences = (s: string) =>
  s
    .match(/[^.!?]+[.!?]+[»”"']*|[^.!?]+$/g)
    ?.map((x) => x.trim())
    .filter(Boolean) || [];
```

**Сборщики сторонних книг должны резать текст ровно этой регуляркой; проще всего — вызвать `sentences()` из `src/core.ts`.** Правило намеренно не «улучшается»: от него зависят индексы строк `t` во всех выпущенных книгах, и любое изменение результата сломает их.

Особенности правила, которые легко упустить:

1. Закрывающими кавычками после знака считаются только `»`, `”`, `"`, `'`. Кавычки `«`, `›`, `‹`, `“` не считаются: в немецком тексте `…Direktor.«` одинокая `«` становится отдельным «предложением» и требует своей строки перевода.
2. Режет после любой `.`, `!` или `?`, даже без пробела и перед строчной буквой: `z.B.` даёт `z.` и `B.`, `am 6. Juni` — `am 6.` и `Juni…`, `gut...«,erwiderte` — `gut...` и `«,erwiderte`.
3. Многоточие `…` (U+2026) предложение не режет.

Пример — «Frau Beate und ihr Sohn», отрывок 2.16:

```
»Küß die Hand, gnä' Frau,« rief der Baumeister, lüftete den grünen Hut mit dem Gamsbart und behielt ihn in der Hand, so daß der weiße Kopf eine Weile unbedeckt blieb. »Wir wollen Sie grad abholen« – und auf ihren fragenden Blick – »haben Sie denn vergessen, gnä' Frau? heut ist ja Donnerstag, Tarockpartie beim Direktor.«
```

`sentences()` даёт 4 элемента, поэтому `t` для этого отрывка должен содержать 4 строки:

1. `»Küß die Hand, gnä' Frau,« rief der Baumeister, … unbedeckt blieb.`
2. `»Wir wollen Sie grad abholen« – … gnä' Frau?`
3. `heut ist ja Donnerstag, Tarockpartie beim Direktor.`
4. `«`

Для «предложения» без букв (как `«`) годится любая непустая строка, например та же кавычка: при показе она отбрасывается.

### Проверка

- Сборка (`packBook()`, сборщик `src/builder-core.ts`) строгая: книгу с несовпадением собрать нельзя. Ошибка указывает адрес и оба числа: `Число предложений перевода не совпадает: 2.16 (ожидалось 4, в переводе 3)`.
- Чтение и импорт (`readBook()`) мягкие: если число строк не совпадает или строка пустая/не строка, книга всё равно открывается, перевод этого отрывка не показывается, а `readBook()` возвращает предупреждения `{ at, expected, got }`. При импорте читалка сообщает «Перевод не показан в N отрывках, первый: 2.16». Остальные проверки (структура, IPA, подсказки, `stats`) строгие и при чтении.

## Деление для показа (не часть формата)

Режим «Параллельно» строит свои строки функцией `readingSentences()` из `src/reading-text.ts`. Это деление другое и на формат не влияет: индексы `t` всегда считаются по `sentences()`.

Граница строки показа — `[.!?…]+`, затем необязательные закрывающие `»«”“"'’›‹)]`, затем пробельные символы и символ, который не является строчной буквой (или конец текста). Поэтому `Frau? heut`, `»Wer?«, fragte`, `gut...«,erwiderte`, `z.B. nichts` и `T., ein` не делятся, а `…` перед заглавной делит. Точка после одно- или двузначного числа (`am 6. Juni`) считается порядковым числительным и не делит. Строки без букв и цифр приклеиваются к предыдущей.

Перевод строки показа — склейка строк `t` тех legacy-предложений, которые перекрываются с ней по буквам (подряд идущие повторы и строки без букв убираются). Если две строки показа делят одно переведённое legacy-предложение, они показываются одной строкой, чтобы перевод не повторялся. Для 2.16 при `t = [A, B, C, "»"]` получается две строки с переводами `A` и `B C`.
