# Provided editions

These three archives are the user's supplied `.fbook` files, preserved byte for byte. `../catalog.json` records their SHA-256 digests, original IDs, statistics and the existing site IDs used for upgrades. `scripts/full-books.mjs` validates them and changes only the manifest's ID/revision for the published editions.

The German texts, translations, lexical entries and pronunciation tables have not been editorially rewritten. Their original provenance statements are retained, including the disclosure that **Die Bremer Stadtmusikanten is a school retelling**, and that all Russian adaptations/dictionaries were generated automatically. The cited source PDFs were not provided with these archives and have not been independently compared. Do not treat a passing format validator as an editorial certification.
