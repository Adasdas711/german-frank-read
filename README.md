# Немецкий по Франку

Автономная читалка немецких книг с русскими подсказками и отдельный сборщик `.fbook`.

## Запуск

Откройте **index.html** в современном Chrome или Edge. Установка, сервер и интернет для чтения не нужны. `fbook-builder.html` — отдельный самодостаточный сборщик. Для перехода между ними положите оба файла рядом. На телефоне можно использовать обычный статический хостинг; данные остаются в IndexedDB браузера.

Встроены **три демонстрационных отрывка книг**, а не полные книги: «Бременские музыканты» (30 отрывков, 946 слов), «Красная Шапочка» (23 отрывка, 623 слова) и «Превращение» (9 отрывков, 203 слова). Примеры расширены примерно в десять раз за счёт продолжения произведений. Они честно помечены «Автотекст». Полные проверенные издания в поставку не включены: нужна человеческая сверка с источником. Исходники демонстраций — `src/demo-source.json`, отдельные файлы — `books/`.

При обновлении приложения новые редакции встроенных примеров устанавливаются автоматически, сохраняя адрес чтения и словарь. Процент пересчитывается с учётом нового объёма. Удалённые пользователем примеры не возвращаются, а более новые пользовательские редакции не заменяются.

## Возможности

- Вкладки «Франк», «Паралель», «Оригинал». Повторный текст без подсказок в режиме Франка по умолчанию выключен; его можно включить переключателем.
- Оглавление, переход клавишами ← →, автоматическое сохранение места, завершение книги.
- Отдельный режим «Только текст»: скрывает интерфейс, сохраняя выбранный формат чтения, тему и размер шрифта.
- Карточка слова: лемма, перевод, IPA, подсказка фразы, сохранение контекста.
- Офлайн eSpeak NG в Worker: IPA → фонемы → WAV → Web Audio; системный немецкий голос как альтернатива. Первый запуск синтезатора требует распаковки и компиляции WASM.
- Загрузка и перетаскивание `.fbook` версии 2, проверки ZIP, CRC-32, структуры, IPA, ссылок, статистики и переводов. Обновление книги по UUID и revision сохраняет данные.
- Слова с поиском, группировкой по книге, CSV и текстовым экспортом Anki с подколодами и выделением формы в контексте. Метка «в Anki» обозначает экспорт, а не подтверждённый импорт в Anki.
- Русский интерфейс по умолчанию, переключение на немецкий в «Настройки → Язык интерфейса». Выбор сохраняется и действует также в сборщике; язык книг и подсказок не меняется.
- Темы, шрифты Literata / Golos Text / системный, размер и скорость речи.
- Резервная копия JSON либо ZIP с книгами. Импорт объединяет слова, сохраняет более свежий прогресс и отдельно спрашивает о замене настроек. Данные импортируются транзакционно.
- Удаление книги сохраняет прогресс и слова; очистка всех данных требует подтверждения.

При обновлении старые настройки автоматически отключают повторный текст без подсказок один раз. После этого ручной выбор сохраняется при перезагрузке и в резервной копии. `npm run test:i18n` проверяет язык, миграцию настроек, сохранение выбора, неизменность текста книг и адаптивность немецкого интерфейса.

## Книжный экран

Чтение по умолчанию открывается на весь экран, с разворотом на широком окне и одной страницей на телефоне. Текст разбивается по реальной высоте страницы, а не по границам отрывков. Библиотека показывает обложки, последние книги и боковую навигацию; на телефоне навигация располагается внизу.

- Касание центра страницы показывает или скрывает управление. Параметры `Aa` открывают шрифт, размер, тему, вид чтения и режимы «Франк», «Паралель», «Оригинал».
- Листание — клавишами ← / →, Page Up / Page Down, горизонтальным свайпом, колёсиком или касанием краёв страницы. Ползунок и оглавление доступны в управлении.
- Подсказка к слову — двойным щелчком, долгим касанием или Enter на слове с клавиатуры. Обычное касание показывает управление.
- Сохраняется не только отрывок, но и позиция немецкого слова внутри него. Она восстанавливается после перезагрузки, изменения шрифта и перехода от разворота к одной странице.
- В `Aa → Вид чтения` остаются «По отрывкам» и «Сплошной текст». Однократное обновление переводит прежний интерфейс на новый книжный экран, затем выбранный вид сохраняется.

`npm run test:pages` проверяет покрытие всех слов страницами без пропусков, развороты и мобильный экран, точную позицию внутри длинного отрывка, восстановление, шрифты, форматы, жесты, словарь, библиотеку и поиск.

## Чтение как в электронной книге

Экран чтения использует единое книжное поле с ограниченной шириной строки. В закреплённой верхней панели переключаются вид чтения и формат текста:

- «По отрывкам» — один блок за раз, переход к следующему кнопкой или клавишами ← / →.
- «Сплошной текст» — вся книга одной лентой с заголовками глав и обычной прокруткой. Отрывки не разделены карточками.
- «Франк», «Паралель», «Оригинал» доступны в обоих видах. Повторный текст без подсказок по-прежнему выключен по умолчанию.

Прокрутка сохраняет текущий отрывок. Перезагрузка, смена формата, раскрытие оглавления и переход в «Только текст» восстанавливают этот отрывок. Вид чтения сохраняется в настройках и резервной копии. Ползунок под книгой и оглавление позволяют перейти к нужному блоку; кнопка озвучки читает текущий отрывок. Словарь открывается поверх страницы и сохраняет адрес того отрывка, в котором выбрано слово.

Это представление существующих книг `.fbook`; загрузка файлов `.epub` не добавляется.

`npm run test:book` проверяет книгу из 60 отрывков в двух главах: прокрутку и восстановление позиции, переходы по оглавлению и ползунку, оба вида и все форматы текста, адрес сохранённого слова, режим без интерфейса, языки, темы и мобильную верстку.

## Режим «Только текст»

Во время чтения нажмите кнопку с книгой «Только текст» в шапке. На экране останется текст текущего отрывка в выбранном формате: по Франку, чистый или параллельный. Подсказки по нажатию на слова в этом режиме не открываются. Тема, шрифт, размер и сохранение места продолжают работать.

- Следующий / предыдущий отрывок — клавиши → / ← либо горизонтальный свайп на сенсорном экране.
- При движении мыши или касании ненадолго появляются кнопки перехода и выхода. Через 1,8 секунды покоя они скрываются.
- Выход — `Esc` или кнопка «Выйти». С клавиатуры временные кнопки доступны через `Tab`.
- Выход возвращает к обычной читалке в том же месте и режиме. Последний отрывок можно завершить так же, как в обычной читалке.

`npm run test:focus` проверяет три формата чтения в светлой и тёмной теме на компьютере, планшете и телефоне, навигацию, скрытие интерфейса, сохранение прогресса, свайп и выход.

## Сборщик

1. Загрузите `book.source.json` из ТЗ (либо несколько частей по порядку) или вставьте JSON. Кнопка «Пример» открывает демонстрационный исходник.
2. Заполните паспорт: название, автор, уровень, источник, лицензия.
3. Загрузите исходный PDF с текстовым слоем. Удалите колонтитулы из извлечённого текста и сравните слова. Красные слова отсутствуют в исходнике, зелёные — лишние. Пунктуация проверяется вручную. OCR не выполняется.
4. Создайте IPA. Личные исправления имеют приоритет над допустимой IPA от ИИ и eSpeak. Свяжите формы со словарными леммами вручную, где автоматическое точное сопоставление не сработало. Можно импортировать и экспортировать личный словарь IPA.
5. Проверьте отрывки: подсказки, смысл, переводы, произношение. Есть добавление/удаление подсказки, разделение и объединение кусков, переход к сомнениям, отмена правки и применение JSON переразметки с проверкой неизменности оригинала. Для замены оригинала выделите правильный фрагмент в поле текста PDF и используйте «Взять из PDF».
6. Скачайте `.fbook`. UUID сохраняется в черновике, revision увеличивается. Архив проверяется обратной распаковкой. Метка «Проверено» доступна только при проверке всех отрывков, отсутствии сомнений, совпадении последней сверки слов и заполненном чек-листе.

Черновик сохраняется автоматически в IndexedDB и скачивается как `.fbook-draft.json`. Сборщик не обращается к ИИ и не отправляет текст в сеть.

## Разработка

Node.js 22.12+ (проверено с 24.19.0). Из корня репозитория:

```sh
npm ci --cache /tmp/npm-cache
npm run build
npm test
npm run typecheck
npm run test:e2e
npm run test:startup
npm run test:layout
npm run test:focus
npm run test:i18n
npm run test:book
npm run test:demos
npm run test:pages
```

`npm run build:demos` пересобирает три примера из `src/demo-source.json` и генерирует IPA новых слов. `npm run test:demos` проверяет расширенные тексты в обоих видах чтения, а также обновление старых примеров без потери слов, адреса чтения и настроек.

Сборка обновляет `index.html` и `fbook-builder.html` в корне. Шрифты, скрипты, ZIP-библиотека, PDF Worker и сжатая WASM встроены; внешних зависимостей во время работы нет. Код интерфейса выполняется перед большим блоком данных WASM в конце HTML, поэтому библиотека открывается до полной загрузки синтезатора. WASM распаковывается только при запросе озвучки. `npm run dev` запускает Vite; после первой сборки страницы разработки доступны как `/reader-dev.html` и `/builder-dev.html`.

`npm run test:e2e` использует установленный `/usr/bin/chromium`, временный HTTP-сервер на 127.0.0.1:4173 и два независимых контекста браузера. Проверяет интерфейс, звук, прогресс после перезагрузки, Anki, перенос резервной копии, экран телефона, извлечение PDF, сборку и импорт книги. Проверяет отсутствие HTTP-запросов приложения, кроме навигации на сам HTML. `TEST_FILE_URL=1 npm run test:e2e` проверяет file://, если политика браузера разрешает локальные файлы.

Исходники модулей — `src/`; общие проверки и упаковка — `src/core.ts`, конвейер сборки книг — `src/builder-core.ts`. Повторная генерация демонстраций: `node scripts/demo.mjs`, затем `npm run build`.

## Интерфейс и темы

Восстановлен исходный макет: на компьютере разделы находятся в верхней шапке, на телефоне — в нижней навигации. На главном экране — только карточка текущей книги с прогрессом, отрывком и кнопкой продолжения. Добавленные боковая панель, блок метода, словарь, книжная полка и загрузка с главного экрана удалены. Загрузка книг доступна в «Текстах», слова — в «Словах».

Фон назначен одновременно `html`, `body` и контейнеру приложения; минимальная высота — высота окна, включая мобильный `dvh`. Тёмная тема не оставляет светлой полосы на высоких экранах. Последний выбор темы кэшируется для раннего оформления до открытия IndexedDB; основное хранилище настроек по-прежнему IndexedDB. «Как в системе» реагирует на смену системной темы.

`npm run test:layout` проверяет 80 сочетаний раздела, светлой/тёмной темы и размеров окна от 320×720 до 1876×1312, а также 1440×1800. Проверяются совпадение фонов документа и тела, заполнение окна, отсутствие горизонтальной прокрутки и выходящих за границы кнопок. Дополнительно проверяются смена системной темы и размеры сборщика. Скриншоты сохраняются в `.test-results/redesign/`.

## GitHub Pages и диагностика запуска

Для GitHub Pages выберите ветку `main` и папку `/ (root)`; вход — `index.html`, не `reader-dev.html`. Файл `.nojekyll` отключает обработку готовых HTML через Jekyll. Обе страницы используют относительные переходы и работают в подпапке репозитория.

Исправлена блокировка первого экрана большой встроенной WASM: раньше модуль в `<head>` ждал загрузки всего HTML, а `<body>` находился после него. Теперь небольшой скрипт интерфейса выполняется в начале тела, а данные синтезатора идут отдельным инертным блоком в конце. `npm run test:startup` удерживает этот блок на сервере и проверяет, что библиотекой уже можно пользоваться. Также проверяются отказ IndexedDB и тайм-аут открытия базы: вместо бесконечной загрузки видны постоянная ошибка и кнопка повторного запуска. Эти действия не очищают пользовательские данные.

После публикации новой версии обновите страницу с перезагрузкой кэша. Если ошибка останется, пришлите показанный текст ошибки. Доступ к самому домену `adasdas711.github.io` из среды разработки возвращает 403; опубликованная версия здесь напрямую не проверена, тесты выполняются в аналогичной подпапке локального сайта.

## Проверка и ограничения

- Цель ТЗ ≤4 МБ пока не достигнута: читалка ~12,7 МиБ, сборщик ~14,1 МиБ. Используется готовая многоязычная WASM eSpeak NG; для уменьшения нужна отдельная немецкая сборка. Исключение озвучки ради размера не применялось.
- Интерфейс проверен в Chromium на ширинах 390, 834 и 1440 пикселей. В данной облачной среде корпоративная политика Chromium блокирует `file://`; браузерные проверки выполняются по локальному HTTP. Сохранение локального HTML после полного перезапуска браузера и поведение Safari/iOS требуют проверки на целевых устройствах. Резервные копии особенно важны при переносе файла.
- Нет полных книг с человеческой проверкой, Zopfli, OCR и `.apkg`. PDF со сложными внешними CMap/шрифтами может потребовать текстовый исходник вместо PDF. Эти возможности не имитируются.
- Сверка PDF — по словам с ограниченным поиском выравнивания, поэтому длинные перестановки показываются как пропуски и добавления. Пунктуация и смысл проверяются человеком. Исходник можно править в JSON; ручная сверка не заменяется автоматической отметкой.
- Лимит книги и распакованного ZIP — 32 МБ, PDF — 64 МБ, JSON исходника — 16 МБ. ZIP-копия большого собрания свыше 32 МБ не поддерживается; сохраните данные JSON и книги отдельно.
- Акустическое качество IPA-конвертации не подтверждено человеческим прослушиванием 100 слов; проверены генерация и декодирование реального WAV, автоматическая совместимость таблицы на формах демонстраций. Время запуска на среднем телефоне не измерено.
- Anki-файл проверен на структуру и содержимое; импорт в установленную настольную Anki в этой среде не выполнялся.
